# Red Hat OpenShift AI Enterprise Governance — Corporate L3 Guide Set

This package contains one deep-dive Markdown handbook per requested topic. Each file is designed for senior enterprise practitioners and includes architecture, implementation from scratch, policy-as-code patterns, Kubernetes/OpenShift examples, controls, evidence, metrics, troubleshooting, runbooks, labs, and review questions.

## Baseline

- Red Hat OpenShift AI Self-Managed 3.4 is used as the supported production baseline for the July 2026 source review.
- OpenShift AI 3.5 was Early Access at that time and is not treated as the production baseline.
- Always validate exact APIs and supported configuration against your deployed OpenShift and OpenShift AI versions.
