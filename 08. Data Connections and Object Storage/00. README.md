## Recommended study order

1. Start with chapters 01–02 to understand the abstraction and S3 protocol.
2. Study chapters 03–06 for provider implementation patterns.
3. Use chapters 07–11 to design buckets, identities, Secrets, endpoints, and TLS.
4. Use chapters 12–15 for pipeline, model, dataset, and backup storage projects.
5. Use chapters 16–20 for performance engineering, security, lifecycle, and incident response.

## Lab safety

- Use an isolated non-production account, namespace, and bucket.
- Never commit live access keys or Secret values.
- Do not use TLS bypass options in production.
- Coordinate load, lifecycle, deletion, object-lock, and recovery tests with storage owners.
- Capture sanitized evidence and request IDs for troubleshooting.
