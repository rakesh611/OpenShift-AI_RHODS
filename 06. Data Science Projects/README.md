# Red Hat OpenShift AI — Data Science Projects Corporate/L3 Training Pack

This package contains 20 numbered Markdown guides. Each guide is designed as a standalone, deep Corporate/L3 study and implementation workbook with architecture, dashboard and CLI workflows, manifests, validation, troubleshooting, security, SRE, backup/restore, GitOps, governance, scenario catalogs, and a capstone.

## Release and usage note

The baseline uses current Red Hat OpenShift AI 3.5 documentation and OpenShift platform concepts. Product CRDs and fields can change. Always discover the installed APIs, use `oc explain`, and export dashboard-created resources before automating release-sensitive objects.

## Recommended learning sequence

1. Start with project creation, ownership, permissions, quotas, storage, and isolation.
2. Build workbenches, connections, pipelines, model serving, and registry integration.
3. Practice collaboration, multi-user access, lifecycle, backup, restore, cleanup, and governance.
4. Complete the capstone in each guide and retain evidence as a portfolio or internal runbook library.
