This package contains 30 separate Markdown guides. Each topic is a standalone project-oriented guide with architecture, implementation, YAML, benchmarks, metrics, troubleshooting, runbooks, capacity, cost, governance, and L3 drills.

- Red Hat OpenShift AI Self-Managed 3.5 documentation

- KEDA 2.20 documentation

## Important usage note

The numeric examples are starting hypotheses, not universal production defaults. Validate every resource, autoscaling, batching, GPU, NUMA, storage, and network change with representative tests on your own cluster and hardware.
