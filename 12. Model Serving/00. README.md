# Red Hat OpenShift AI — Model Serving Corporate/L3 Knowledge Pack

This pack contains one detailed Markdown file for each requested Model Serving topic.

## Baseline

- Production design baseline: Red Hat OpenShift AI 3.4 GA and KServe RawDeployment.
- OpenShift AI 3.5 material is treated as Early Access or preview where the release documentation identifies it that way.
- KServe Serverless and ModelMesh are described as deprecated migration context, not recommended greenfield architecture.
- Examples must be checked against the installed cluster CRDs, `oc explain`, Red Hat support matrices, enabled runtimes, and organizational policy.

## Recommended study method

1. Read files 01–10 for architecture and control-plane foundations.
2. Build files 11–22 as implementation labs.
3. Use files 23–28 for operations, SRE, performance, and rollback.
4. Use files 29–30 as incident simulations.
5. Commit your edited manifests to Git and replace every placeholder.
6. Track commands, evidence, metrics, and lessons learned in a lab journal.
