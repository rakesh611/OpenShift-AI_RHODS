# Red Hat OpenShift AI Hands-On Lab Practice — Corporate L3

Baseline: Red Hat OpenShift AI Self-Managed 3.4.2 and OpenShift Container Platform 4.19+.

This pack contains one standalone Markdown lab per requested topic. Each topic file includes:

- architecture and prerequisites;
- from-scratch implementation workflow;
- CLI commands and reference manifests;
- functional, security, and observability acceptance tests;
- rollback and production hardening;
- 100 detailed troubleshooting cases;
- 90 operational drills;
- 50 corporate interview questions with model answers;
- 40 hands-on assignments;
- change, incident, and certification checklists.

## Important usage notes

1. Replace all placeholders before running commands.
2. Validate every custom resource against the live cluster with `oc explain` and `oc apply --dry-run=server`.
3. Use current Red Hat supported-configuration and lifecycle documentation before production changes.
4. Do not store plaintext secrets in Git.
5. Some APIs, especially hardware-profile schemas, can evolve between OpenShift AI minors; export a dashboard-created known-good object when necessary.
