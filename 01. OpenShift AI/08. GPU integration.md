1. What is GPU Integration in OpenShift AI?

GPU integration means enabling Kubernetes/OpenShift workloads to consume physical GPU hardware from worker nodes.

OpenShift AI uses:

Kubernetes Device Plugin Framework

NVIDIA GPU Operator

Node Feature Discovery (NFD)

RuntimeClass

CUDA libraries

GPU scheduling

MIG profiles

GPU-aware monitoring

The GPU becomes a schedulable resource like:

CPU

Memory

HugePages

Example:
```yaml
resources:
  limits:
    nvidia.com/gpu: 1
```
2. Why GPUs Are Needed in AI

CPU vs GPU

| CPU                   | GPU                             |
| --------------------- | ------------------------------- |
| Sequential processing | Massive parallel processing     |
| Few cores             | Thousands of CUDA cores         |
| Better for OS/apps    | Better for AI matrix operations |
| Low throughput        | High throughput                 |

AI operations like matrix multiplication:
```plain
A x B = C
```
need parallel execution.

Frameworks using GPU:

TensorFlow

PyTorch

RAPIDS

CUDA

JAX

ONNX Runtime

5. Node Feature Discovery (NFD)

NFD detects hardware capabilities automatically.

Example labels:
```bash
feature.node.kubernetes.io/pci-10de.present=true
feature.node.kubernetes.io/cpu-model.vendor_id=NVIDIA
```
Check:
```bash
oc get nodes --show-labels
```
6. Device Plugin Framework

Kubernetes cannot use GPU directly.

The NVIDIA Device Plugin:

Discovers GPUs

Registers GPUs with kubelet

Advertises GPU resources

Example:
```bash
oc describe node worker01
```
Output:
```plain
Capacity:
  nvidia.com/gpu: 4
```

9. GPU Scheduling in OpenShift AI

Example notebook:
```yaml
resources:
  limits:
    nvidia.com/gpu: 1
```
Scheduler places pod only on GPU nodes.

GPU Taints & Tolerations

GPU nodes are usually tainted.

Example:
```bash
kubectl taint nodes gpu-node gpu=true:NoSchedule
```
Notebook toleration:
```yaml
tolerations:
- key: gpu
  operator: Equal
  value: "true"
  effect: NoSchedule
```

14. MIG (Multi-Instance GPU)

Supported:

A100

H100

MIG splits GPU into logical GPUs.

Example:
```plain
1 A100 → 7 smaller GPUs
```
Benefits:

Isolation

Better utilization

Multi-tenant AI clusters

MIG Example
```bash
nvidia-smi mig -cgi 19 -C
```
Kubernetes resources:
```plain
nvidia.com/mig-1g.5gb
```
