# 22. Training performance tuning

> Operational deep-dive: architecture, implementation, governance, tuning, troubleshooting, and production validation.

## 1. Executive summary

- Focus: evidence-based end-to-end training performance optimization.
- Capstone: Establish a baseline, profile bottlenecks, apply one change at a time, and publish a capacity curve.
- Use immutable code, data, image, and model identities.
- Treat a model as a governed software-and-data artifact.
- Kubeflow Trainer v2 uses `TrainJob` plus training runtimes; older clusters may contain `PyTorchJob`.
- Verify exact product version, support tier, accelerator matrix, and framework compatibility.

## 2. Learning objectives

- Explain evidence-based end-to-end training performance optimization across architecture, APIs, workloads, data, security, and operations.
- Create project resources from scratch with least privilege and quotas.
- Develop in a workbench without hidden notebook-state dependency.
- Package code in a pinned non-root image.
- Execute as Job, pipeline component, or TrainJob as appropriate.
- Capture parameters, metrics, artifacts, code, data, and image identities.
- Export and validate a clean immutable model artifact.
- Tune only after measuring a stable baseline.
- Troubleshoot scheduling, image, storage, S3, RBAC, framework, GPU, and distributed failures.
- Define promotion, rollback, retention, and operational ownership.

## 3. Architecture and responsibility model

1. Git holds reviewed code and declarative configuration.
2. CI builds and scans an image and records its digest.
3. Approved data is accessed through a connection or immutable S3 prefix.
4. Workbench exploration is converted to repeatable batch or pipeline execution.
5. MLflow and pipeline metadata capture lineage and evidence.
6. Exported artifacts include preprocessing, schema, metrics, environment, and hashes.
7. Quality, security, performance, and cost gates precede promotion.
8. Operations receives SLOs, dashboards, runbooks, capacity, and rollback.

```python
# train_sklearn.py
from pathlib import Path
import json, os, joblib, mlflow, pandas as pd
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import roc_auc_score
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import OneHotEncoder, StandardScaler

data = Path("/workspace/data/processed")
out = Path("/workspace/artifacts/sklearn")
out.mkdir(parents=True, exist_ok=True)
train = pd.read_parquet(data / "train.parquet")
valid = pd.read_parquet(data / "validation.parquet")
num = ["tenure","monthly_charges"]
cat = ["contract_type"]

pre = ColumnTransformer([
    ("num", Pipeline([("imp",SimpleImputer(strategy="median")),("scale",StandardScaler())]), num),
    ("cat", Pipeline([("imp",SimpleImputer(strategy="most_frequent")),("onehot",OneHotEncoder(handle_unknown="ignore"))]), cat),
])
model = Pipeline([("preprocess",pre),("classifier",LogisticRegression(max_iter=1000,class_weight="balanced"))])
if os.getenv("MLFLOW_TRACKING_URI"):
    mlflow.set_tracking_uri(os.environ["MLFLOW_TRACKING_URI"])
mlflow.set_experiment(os.getenv("MLFLOW_EXPERIMENT_NAME","churn-training"))
with mlflow.start_run():
    model.fit(train[num+cat], train["churn"])
    p = model.predict_proba(valid[num+cat])[:,1]
    auc = roc_auc_score(valid["churn"], p)
    mlflow.log_metric("validation_roc_auc", float(auc))
    joblib.dump(model, out / "model.joblib", compress=3)
    (out / "metrics.json").write_text(json.dumps({"roc_auc":auc}, indent=2))
    mlflow.log_artifacts(str(out), artifact_path="model")
```

```python
# train_pytorch.py
import json, os, random
from pathlib import Path
import numpy as np, torch
from torch import nn
from torch.utils.data import DataLoader, TensorDataset

seed=42
random.seed(seed); np.random.seed(seed); torch.manual_seed(seed)
if torch.cuda.is_available(): torch.cuda.manual_seed_all(seed)
device=torch.device("cuda" if torch.cuda.is_available() else "cpu")
out=Path("/workspace/artifacts/pytorch"); out.mkdir(parents=True,exist_ok=True)
x=torch.randn(20000,32); y=(x[:,:4].sum(dim=1)>0).long()
loader=DataLoader(TensorDataset(x,y),batch_size=int(os.getenv("BATCH_SIZE","256")),
                  shuffle=True,num_workers=int(os.getenv("DATALOADER_WORKERS","2")),
                  pin_memory=torch.cuda.is_available())
model=nn.Sequential(nn.Linear(32,128),nn.ReLU(),nn.Dropout(.1),nn.Linear(128,2)).to(device)
opt=torch.optim.AdamW(model.parameters(),lr=1e-3); loss_fn=nn.CrossEntropyLoss()
scaler=torch.amp.GradScaler("cuda",enabled=device.type=="cuda")
for epoch in range(5):
    total=0.0
    for features,labels in loader:
        features=features.to(device,non_blocking=True); labels=labels.to(device,non_blocking=True)
        opt.zero_grad(set_to_none=True)
        with torch.autocast(device_type=device.type,dtype=torch.float16,enabled=device.type=="cuda"):
            loss=loss_fn(model(features),labels)
        scaler.scale(loss).backward(); scaler.step(opt); scaler.update(); total+=loss.item()
    print(json.dumps({"epoch":epoch+1,"loss":total/len(loader)}))
torch.save({"model_state_dict":model.state_dict(),"optimizer_state_dict":opt.state_dict(),"epoch":5,"seed":seed},out/"checkpoint.pt")
torch.save(model.state_dict(),out/"model_state.pt")
```
