Huge datasets (TB/PB scale)

4. Kubernetes Storage Foundations

Since OpenShift AI runs on Kubernetes/OpenShift, storage relies on:

A. Persistent Volumes (PV)

Cluster storage resources.
```yaml
kind: PersistentVolume
```
Example:

Ceph block device

NFS share

AWS EBS disk

B. Persistent Volume Claims (PVC)

Requested by workloads.
```yaml
kind: PersistentVolumeClaim
```
Notebook pods and pipelines consume PVCs.

C. Storage Classes

Dynamic provisioning mechanism.
```yaml
kind: StorageClass
```
Examples:

gp3-csi

ocs-storagecluster-ceph-rbd

nfs-client

local-storage

5. CSI (Container Storage Interface)

Modern OpenShift AI storage uses CSI drivers.

CSI allows Kubernetes to communicate with storage systems.

CSI Components
```plain
Kubernetes
    |
    v
CSI Driver
    |
    +---- Ceph
    +---- AWS EBS
    +---- Azure Disk
    +---- NetApp
    +---- Dell EMC
```
Benefits

Dynamic provisioning

Snapshots

Cloning

Expansion

Encryption

Multi-cloud support

12. CephFS vs RBD

| Feature            | CephFS    | RBD        |
| ------------------ | --------- | ---------- |
| Type               | File      | Block      |
| Shared Access      | Yes       | Usually No |
| Notebook Sharing   | Excellent | Limited    |
| DB Workloads       | Moderate  | Excellent  |
| AI Dataset Sharing | Excellent | Moderate   |

24. Storage Classes Example
```yaml
apiVersion: storage.k8s.io/v1
kind: StorageClass
metadata:
  name: ai-fast-storage
provisioner: openshift-storage.rbd.csi.ceph.com
parameters:
  pool: ocs-storagecluster-cephblockpool
reclaimPolicy: Delete
allowVolumeExpansion: true
```
25. Dynamic PVC Example
```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: notebook-storage
spec:
  accessModes:
    - ReadWriteOnce
  storageClassName: ai-fast-storage
  resources:

```
